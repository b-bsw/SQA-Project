About the numbers

How results are counted

Each CSV row is one recorded result for a target in a round. Revealing rate is revealing results divided by all recorded results, including unavailable ones. Line and branch coverage show two arithmetic averages: recorded only divides by the number of numeric coverage values; all applicable results divides by total results minus successful zero-total metrics (B, N/A). Failed measurements (A) count as 0%; recorded 0% values count in both. Default zero totals from a failed measurement are A, not N/A. Unknown cases remain unresolved. A target in two rounds counts twice.

Coverage evaluates buggy-side measurements. Latest FAIL excludes stale coverage. Valid buggy coverage is retained when paired verdict is NOT_AVAILABLE because fixed execution or paired validation is unavailable. Verdict requires both buggy and fixed execution. GA uses V2 coverage and historical paired validation, which may use different test suites.
